# Ste na rade

Interaktívna stránka o liekovej politike z pohľadu lekárne: dnešný doklad,
problém, ktorý na ňom nevidno, a návrh, ako by to mohlo byť lepšie.

**Stránka:** https://jurzon.github.io/ste-na-rade/

Statické HTML, CSS a JavaScript bez knižníc, cookies a sledovania. Nič, čo
návštevník urobí, sa nikam neposiela. Písmo Caveat je pod licenciou SIL Open
Font License 1.1 (`pisma/OFL.txt`).
